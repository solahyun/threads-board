스레드 패션 보드 웹앱

추천 배포: GitHub Pages
1. GitHub에서 새 repository 생성 (예: thread-fashion-board)
2. 이 폴더의 index.html, manifest.webmanifest, sw.js 3개 파일 업로드
3. Repository Settings > Pages
4. Build and deployment에서 Deploy from a branch 선택
5. Branch: main / (root) 선택 후 Save
6. 생성된 https 주소를 iPhone Safari에서 열기
7. 공유 버튼 > 홈 화면에 추가

기능
- 4컷: 2x2
- 6컷: 3x2
- 8컷: 4x2
- iPhone 사진 보관함에서 다중 선택
- 개별 사진 확대/좌우/상하 크롭
- 사진 순서 변경
- 번호 ON/OFF
- 1080x1350 JPG 저장
- 사진은 서버 업로드 없이 브라우저에서만 처리
